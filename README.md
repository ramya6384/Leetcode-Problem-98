LeetCode 98 – Validate Binary Search Tree

Problem Number: 98
Platform: LeetCode
Topic: Binary Trees, Binary Search Tree (BST)
Language: Java

Problem Description

Determine whether a given binary tree is a valid Binary Search Tree (BST).

Approach

A valid BST must satisfy these conditions:

- All nodes in the left subtree contain smaller values than the root.
- All nodes in the right subtree contain greater values than the root.
- Both left and right subtrees must also be valid BSTs.
